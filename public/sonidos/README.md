# Sonidos del juego

Coloca aquí dos archivos:

- `exito.mp3` — campanita / "ding" que suena cuando un alumno acierta.
- `pato.mp3` — el clásico "cuack" que suena cuando un alumno falla.

Pueden ser archivos cortos (1–2 segundos) en MP3 u OGG. Si los renombras
o cambias la extensión, ajusta `src/hooks/useSonidos.ts`.

Si no existen, el juego sigue funcionando — simplemente no suena nada.
